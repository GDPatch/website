<Steps>
1. [Download the latest release of GDPatch](https://github.com/GDPatch/GDPatch/releases/latest/download/gdpatch_loader.dll).
2. Copy `gdpatch_loader.dll` into your game install and rename it to `winmm.dll`.

   <FileTree>
    - game.exe
    - **winmm.dll**
   </FileTree>

3. Set the environment variable `WINEDLLOVERRIDES="winmm=n,b"`. For games running under Steam, you can set the game's Launch Options in Steam (right click > Properties > General):

   ```
   WINEDLLOVERRIDES="winmm=n,b" %command%`
   ```

4. Start the game.
</Steps>
